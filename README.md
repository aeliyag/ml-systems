# Machine Learning for Computer Systems

Course website and other content for the Machine Learning for Computer Systems course.

## Contents

- `docs/` - Course website
  - `assignments/` - Course assignments
  - `slides/` - Lecture slides
  - `midterm/` - Old midterms and solutions
  - `final/` - Old finals and solutions
  - `notebooks/` - Jupyter notebooks
  - `book/` - Course book content
  - `syllabus.md` - Course syllabus

## Preview the textbook

From the repo root:

```bash
./docs/book/serve.sh
```

That serves the book at http://127.0.0.1:8765/. Open it in Safari. Press Ctrl-C to stop the server.
